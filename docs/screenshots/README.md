# Android UI evidence

These screenshots are generated on phone A063 (Android 15) by
`ThesisScreenshotsTest` using the real production Compose screens/renderers and
representative deterministic sample state:

- `activity_tracker_home.png` — live activity, steps, calories and six duration buckets;
- `activity_tracker_history.png` — completed/interrupted history and export states;
- `activity_tracker_map.png` — shared historical route renderer with activity colors;
- `activity_tracker_data.png` — two-device BLE v6 dataset control.

The displayed numbers are illustrative UI fixtures, not additional experiment
measurements. Classification and evaluation evidence remains in `dataset/results`
and the validation documents.
